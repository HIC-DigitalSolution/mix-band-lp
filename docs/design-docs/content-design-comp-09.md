# 内容デザインカンプ09の決定

## 依頼者の判断

依頼者は「色の競合を整理した配色比較06のデザインが一番良かった」と判断した。
比較07で広げたブルーバイオレットの面と大きなオレンジの光は採用せず、
比較06の濃紫、電気的な紫、ラズベリーピンク、淡いピンクの配分へ戻す。

## カンプ08から変えたこと

- イベント理解をスモーキーピンクから、紫からラズベリーピンクへ移る広い光の面に変更
- チャイム面のコバルト寄りの青を外し、濃紫の中へ電気的な紫を光として重ねる
- チャイムはオレンジの大きな円から、紫とピンクが重なる2つのネオン円へ変更
- オレンジ `#FF8A1F` は小さな火花、点、細線だけに戻す
- 体験価値と開催情報は、比較06と同じ淡いピンクと白いカードで静かに読ませる
- ゼブラは淡い面の端にまとまった面積で置き、本文の背面には置かない
- CTAは濃紫へ戻した終盤に置き、ネオンピンク `#FF2D95` の発光する一面にする

主な色は、濃紫 `#24102E`、電気的な紫 `#6338D4`、ラズベリーピンク
`#C91F70`。本文面は `#F2D6DF` と `#FFF7FA`。比較05で競合した広い青と
オレンジは復活させない。

## 変えていないこと

内容順、確定コピー、支給バナーの仮置き、店舗選択ダイアログ、単一CVはカンプ08を継承する。
リボン、料金、受付時間、実績、お客さまの声、FAQは追加しない。
