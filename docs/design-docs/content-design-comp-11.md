- **Status:** Paradox Live型の全面FVを反映。375pxブラウザ表示の最終確認待ち

## 依頼者の指定

依頼者は [Paradox Live 5th Anniversary](https://paradoxlive.jp/5thanniversary/) のように
FVを横幅いっぱいにし、支給バナー上部のピンクの焼き込み文章を外し、タイトルを大きく見せ、
左上にロゴを置きたいと指定した。FVにはアニメーション効果も加える方向で検討する。

## 参考サイトから取ったこと

2026-09-08に実画面とCSSを再確認した。参考FVは、背景、メインビジュアル、手前の紙片・観客、
ロゴ、装飾を別レイヤーで重ね、背景に3秒周期の明滅、観客に小さな上下動を付けている。
導入後は全面ビジュアルが画面を占め、ロゴは端へ置かれている。

MIXへ借りるのは「全面ビジュアル」「端のロゴ」「複数レイヤー」「小さなループ」という構成だけ。
参考サイトのロゴ、写真、配色、チケットや紙片の素材は流用しない。

## FVの変更

- phone内のFV写真を左右の余白なしで横幅いっぱいにした
- 元バナーの上部44pxだけをカットした `mix-band-key-fv-crop.webp` を作成した
- AI編集版は人物の顔や衣装まで変わったため採用せず、元画像の決定的なトリミングを使う
- `asobibar-logo-light.svg` を左上へ置いた
- 写真を約7〜11%の範囲でゆっくりズームする
- 画面全体の光を7秒で呼吸させ、左右端の光線だけを3〜4秒で走らせる
- `prefers-reduced-motion: reduce` では全て停止する

メインタイトルは支給バナー内のものを維持し、横幅いっぱい化と上部余白の削減で従来より大きく
見えるようにした。別の文字を重ねて二重にしない。

## 変更していないこと

比較06の濃紫、電気的な紫、ラズベリーピンク、淡いピンクの配色、6区間の内容順、
店舗選択ダイアログ、CTAの役割はカンプ10から継承する。オレンジは火花・点・細線だけに残し、
リボンは使わない。

## 確認状況

元バナー、上端をカットしたFV用画像、ASOBIBARロゴを目視した。HTMLParserでカンプ11を解析し、
既存カンプ09・10の全体PNGと変更意図を比較した。

ローカルHTTPサーバー経由の375pxブラウザ表示は、実行上限による自動承認拒否で未確認である。
そのため、本番実装へ進む前に、横幅いっぱいの切り替わり、ロゴの可読性、タイトルの拡大率、
光線が人物とコピーへ重ならないことをHTTP経路で確認する。
