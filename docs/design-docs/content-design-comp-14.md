# 内容デザインカンプ14の決定

- **Date:** 2026-09-08
- **Status:** SOUND TRIPの人物スケールへ寄せた比較案。375pxのHTTP表示確認待ち
- **Comp:** `design/mix-lp-content-design-comp-14.dc.html`
- **Previous candidate:** `design/mix-lp-content-design-comp-13.dc.html`

## 見直しの理由

カンプ13は人物の頭・髪・肩・腕を描き込み、人物そのものがファーストビューの主役に見えた。依頼者から
「SOUND TRIPのサイトの人のシルエットの感じをイメージしてほしい」と指示を受けたため、参考サイトで確認した
「大きな有機形の中に、小さな人物・記号をまとめる」スケールへ戻す。人物のポーズを説明するのではなく、背景の
一部として人の気配を置く。

## 採用した表現

- `.intro` の右端へ、幅124px・高さ154pxの小さな人物記号を1組だけ置く
- 2つの頭、髪の塊、短い腕、中央のグラス、2本の波線と火花だけで「人が集まり乾杯する」ことを示す
- 左を濃紫、右を電気的な紫とし、輪郭は淡いピンク／紫。オレンジはグラスと火花だけに残す
- 顔の表情、衣装、指、写真の人物の描写は持ち込まない。本文の中央域と焼き込みタイトルから離す
- SVGは専用レイヤーに分け、CSSは配置・色・重なりを担当する。リボンや汎用的な丸いblobは使わない

これはSOUND TRIPの人物イラストや輪郭をコピーするものではない。借りるのは、広い色面に対して人物記号を
小さく置き、余白とスケール差で画面に呼吸を作る考え方だけである。参照サイトの実物の色、ロゴ、人物の造形は
MIXへ流用しない。

## 配置と動き

人物記号はイベント理解セクションの大きな有機形の端へ寄せ、本文より一段下のレイヤーに置く。画面の外へ
少しはみ出させ、中央の文章を空ける。人物・波線・グラス・火花は静止させ、カンプ11から引き継いだ写真の
微細なズーム、光の呼吸、端の光線だけを動かす。`prefers-reduced-motion: reduce` では既存の動きを停止し、
人物の光彩フィルターも外す。

## 変更しないこと

比較06の濃紫・電気的な紫・ラズベリーピンク・淡いピンクの役割、SOUND TRIPの構成文法、全面FV、左上ロゴ、
6区間の内容順、店舗選択ダイアログ、CTAの役割は維持する。リボンは使わず、オレンジはグラス・火花・小さな
罫だけに残す。本番HTML・Sass・JSはまだ変更しない。

## 確認状況

カンプ14へ小さな人物記号、波線、中央の乾杯を反映し、カンプ13の大きな上半身ポーズを置き換えた。HTMLParserは
296 start-tags / errorsなし、`harness-check.mjs` は all machine-verified invariants passed（manual 24行）、
`git diff --check` も問題なしだった。`tools/render.sh` はこの環境のQuickLook描画が失敗しており、ローカルHTTP
サーバー経由の375px表示も自動承認の実行上限で未確認である。実装へ進む前に、人物記号が本文・日付・CTAを
覆わないこと、端のはみ出しが横スクロールを作らないことをHTTP経路で確認する。
