## 構成

第一稿は、情報のない実績・声・FAQを外し、次の6区間へ絞る。

**WHO / HERO → 共感・イベント理解 → 得られる体験 → 仕組み → 開催情報 → CTA**

FooterはCTAの後ろに置く。料金・受付時間・店舗一覧の空欄は表示しない。

### 01 WHO / HERO

**役割:** 広告から来た人が、対象・内容・開催条件を最初の画面で把握する。

- 対象表示: **20〜30代の男女へ**
- キーアート: 支給バナーを仮置き
- 読める文字として置く3点:
  - **恋愛リアリティ体験**
  - **最大4〜6組**
  - **日〜木曜日限定**
- 開催期間: **2026年10月1日〜10月31日**

支給バナーの焼き込み文字へ重ねず、バナー直下の独立した要約として見せる。

### 02 共感・イベント理解

**役割:** 何のイベントかを理解させ、来店前に求めている刺激・関係の変化・非日常へつなぐ。

**見出し案:**

> 見るだけじゃない。あなたが参加する恋愛リアリティショー

**本文案:**

> 恋愛リアリティショーを、ASOBIBARで実際に体験できるイベントです。いつもと違う刺激のなかで、ASOBIBARならではの感動体験と、関係が動くきっかけ、非日常の一夜を楽しめます。

上記は依頼者から確認した内容を整理したコピー案。「関係が動く」はカップル成立を保証する
表現ではなく、体験への期待として使う。

### 03 得られる体験

**役割:** 参加者側の価値を3点以内で示す。

| 見出し案 | 伝える内容 |
| --- | --- |
| いつもと違う刺激 | 普段の来店とは違う高揚感を楽しんでもらう |
| 関係が動くきっかけ | カップル成立につながる可能性を示す |
| 非日常を体験 | ASOBIBARを舞台にした恋愛リアリティショーへ参加する |

「必ずカップルになれる」とは書かない。カップル成立は保証ではなく、目指す結果として扱う。
再来店は参加者へ掲げるメリットではなく、公開後に見る運営側の成果として扱う。

### 04 仕組み

**役割:** 体験がどのように動き出すかを、明かしてよい範囲だけで伝える。

**見出し案:**

> チャイムが鳴ったら、物語が動き出す

**掲載する事実:** 

- チャイムが鳴る
- そこからお題が出される
- 最大4〜6組のグループが交差する

お題の内容と進行の詳細は書かない。「チャイムが鳴るまで分からない」という期待を残す。

### 05 開催情報

**役割:** 参加できる時期と条件だけを、静かな情報面で迷わず読ませる。

| 項目 | 表示 |
| --- | --- |
| 開催期間 | 2026年10月1日〜10月31日 |
| 開催曜日 | 日〜木曜日限定 |
| 参加条件 | オレンジバンド |

全店開催だが、依頼者の指示により店舗一覧は載せない。料金・受付時間も第一稿では載せない。

### 06 CTA

**役割:** 体験への期待を、一つの具体的な行動へつなげる。

**ページ側のボタン文言:**

> 参加する店舗を選ぶ

ボタンを押すと、ページ上に店舗選択ダイアログを表示する。店舗一覧は本文には置かず、
このダイアログ内だけに表示する。店舗を選ぶと、その店舗の公式LINEへ移動する。

**ダイアログのコピー:**

- 見出し: **参加する店舗を選んでください**
- 補足: **選んだ店舗の公式LINEが開きます**
- 店舗ごとの行動: **公式LINEへ**
- 閉じる操作: **閉じる**

ダイアログは、店舗名と公式LINEへのリンクを同じ行に置く。背景クリック、閉じるボタン、
Escキーで閉じられ、閉じた後は「参加する店舗を選ぶ」ボタンへ操作位置を戻す設計にする。
店舗名と各公式LINE URLは実装前の支給待ち。

## 今回外すセクション

- お客さまの声
- 独立した限定性
- 料金
- 受付時間
- 店舗一覧

開催終了日は開催情報内で明示するため、「残りわずか」などの限定表現は追加しない。

## デザインへの割り当て

- FV直下の3点は、同じ形の小さな情報単位としてまとめる
- 仕組みの面は濃紫を地にし、電気的な紫とピンクのネオン円が重なる光でチャイムを見せる
- オレンジは小さな火花・点・細線だけに置く
- 得られる体験は同じ輪郭を3回反復し、内容の並列性を示す
- 開催情報は白または淡いピンクの静かな面にする
- CTAで濃紫へ戻し、ネオンピンクのべた塗りをボタンだけに使う
- 店舗選択ダイアログは開催情報と同じ白い面を使い、店舗名を探しやすくする

SOUND TRIPから取った、有機形がセクション境界へ食い込む構成は維持する。
リボンは使わず、本文の背面へゼブラ柄を置かない。
