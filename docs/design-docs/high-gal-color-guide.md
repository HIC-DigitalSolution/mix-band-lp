# ハイギャル配色術「黄色×ピンク」設計・カラーガイドライン

本ドキュメントは、派手で主張の強い色同士（イエロー×ピンク）を組み合わせながらも、子供っぽさを排除し、洗練されたラグジュアリー（海外ブティックホテルのような世界観）を構築するための配色設計ガイドラインです。
Claude Code等のAIアシスタントに前提知識（配色ハーネス）として読み込ませることで、UI/UXデザイン、LPデザイン、プロダクト・インテリアのカラー設計における高度な色彩コントロールを自律的に実行させるために使用します。

---

## 1. カラー設計の基本概念と対立の調和

一般に「黄色」と「ピンク」の組み合わせは、原色同士をそのままぶつけるとおもちゃっぽくごちゃごちゃした印象になりがちです [2]。
本配色術では、あえて主張の強いアニマル柄（ゼブラ柄等）をぶつけながらもラグジュアリー感を醸し出す、高度な色彩コントロール（引き算と質感の追加）のロジックを定義します [2, 3]。

---

## 2. 4つの核心配色ロジック

### ① 主役のイエローは「マスタード（少し暗め）」を選ぶ
* **ロジック**: 黄色を空間やデザインの主軸に据える際、おもちゃっぽさやカジュアル感の出やすい「ひまわりのような原色の黄色」を避け、少し深みとツヤのある**マスタードイエロー**を採用します [3, 4]。
* **効果**: 鮮やかさは保ちつつ、大人っぽい重厚感と安定感を演出します [4]。

### ② 面積の広いピンクは「彩度を落とす（くくませる）」
* **ロジック**: ピンクの使い方のポイントは「彩度の引き算（使い分け）」にあります [5]。
  * **高彩度（ビビッドピンク）**: ネオンライトやクッションなどの「点」で効かせる [5]。
  * **低彩度（ダスティピンク / スモーキーピンク）**: 壁面や背景などの「面（広い面積）」に用いる [5]。
* **効果**: 背景をくすませることで、主役のマスタードイエローを邪魔せず、空間全体に上品なヌーディーさと大人っぽい高級感を与えます [5, 6]。

### ③ 「光」と「質感（ゴールド）」のレイヤード
* **ロジック**: 派手色同士のチープさを消し、洗練させるために「光」と「金属光沢」をレイヤーとして重ねます [6]。
  * **線状の光（ネオンサイン等）**: 色と柄の間に非現実的な空気感を作り、散らかりがちな要素をまとめます [6]。
  * **ゴールドの光沢**: イエローと同調しながら高級感をプラスし、アニマル柄等の野性味を「ラグジュアリー」へと昇華させます [6]。

### ④ 白（無彩色）による「色彩ノイズのリセット」
* **ロジック**: 強いメインカラーとパターン（柄）で囲まれた中央部分に、清潔感のある「ホワイト（または大理石調）」を投入します [7]。
* **効果**: 色・柄過多による視覚的な疲れを防ぐ**「逃げ場（余白）」**として機能します [7]。これにより、周囲に散らばる細々としたカラフルな小物さえも、散漫にならずに「ポップなアクセント」として引き立たせることができます [8]。

## 3. Web/LPデザイン・インテリア共通の再現ルール

デザインを実装・再現する際は、以下のトーンと配分比率（ハーネスルール）を適用してください。

1. **メイン（アクセント・主役）**: 
   - 家具やメインのコンポーネント（ファーストビュー、ヒーローセクション等）に、ツヤと深みのある**マスタード系イエロー**を配置 [4, 8]。
2. **ベース・背景（広面積）**: 
   - 背景や面要素には、グレーやベージュを内包した**くすみピンク（低彩度ピンク）**を敷く [5, 8]。
3. **アクセント（極小面積）**: 
   - **高彩度なネオンピンク**は「点」または「線（フチ・ライト）」としてのみ使用する [5, 8]。
4. **パターン（柄）の統合**: 
   - 柄を導入する場合、メインカラー2色（マスタードイエロー×ピンク）をブレンドしたパターン（例：イエロー×ピンクのゼブラ柄）を採用することで、無関係な色彩ノイズを増やさずにまとまりを出す [8]。
5. **リセットエリア（余白）**: 
   - ユーザーの視線が集まる中央部分やコンテンツの区切りには、**白（大理石調テクスチャ含む）**または**ゴールド**を「逃げの余白」として配置し、全体のバランスを整える [7, 8]。

## 4. Claude Code等への実装指示用プロンプトテンプレート

AIに本カラーガイドラインを遵守したコンポーネントやデザインコードを生成させるための指示書です。

```markdown
# 役割
あなたは高度な色彩設計とトレンド感のあるUI構築を得意とする、一流のクリエイティブ・フロントエンドエンジニアです。

# タスク
「黄色×ピンク」を基調としつつ、海外ブティックホテルのような洗練されたラグジュアリー感を醸し出す[UIコンポーネント/ヒーローセクション/キャンペーンLP]のコーディング（HTML/Tailwind CSS）を行ってください。

# 色彩設計の制約条件（本ナレッジに基づく指示）
1. **イエローの指定**:
   - 安っぽい原色の黄色（#FFFF00等）は禁止します。
   - 深みとツヤのあるマスタードイエロー（例: `bg-amber-600` や `text-yellow-700`、あるいは微細なグラデーション）を主役の要素（ボタンやメインカード等）に適用してください。
2. **ピンクの使い分け（彩度コントロール）**:
   - 広面積の背景には、グレーやベージュをブレンドした低彩度のスモーキーピンク（例: `#E2C2C6` など）を採用し、上品なヌーディーさを演出してください。
   - 高彩度なビビッドピンク（ネオンピンク）は、フォーカスさせたい特定の枠線（ボーダー）や小さなアイコン、点状の要素（ドット）など「点」でのみ効かせてください。
3. **質感とレイヤード（ゴールド of Tailwind）**:
   - 枠線やシャドウ、テキストのグラデーションに、イエローと同調するリッチな「ゴールド（金色のグラデーションや、滑らかな光沢感）」を表現に組み込み、アニマル柄などの野性的・派手な要素をラグジュアリーに昇華させてください。
4. **ノイズのリセット（白の逃げ場）**:
   - ビジュアルの中心や文字情報の可読エリアには、すっきりとした「ホワイト（大理石調の非常に薄いグレーパターン含む）」を配置し、色彩による目の疲れ（視覚的ノイズ）をリセットする余白を必ず確保してください。
```
