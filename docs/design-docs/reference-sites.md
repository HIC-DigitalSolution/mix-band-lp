## 1. KBC創立70周年 —— 浮いているオブジェクト

`https://kbc.co.jp/70th/`

依頼者の言葉: **所々オブジェクトが浮いている。意味合いとしては交流がMIXするので、
今回のLPにもうまく使えそう。**

### 実装から読み取ったこと

| | |
| --- | --- |
| 構造 | `div`（配置）→ `em`（動き）→ `img`（絵）の**3層。1層1役** |
| 素材 | `assets/line/hero01〜14.webp` —— **切り抜きのリボン**。ディレクトリ名が `line` |
| 動き | `translateY` を **-3%〜+5%** だけ。単位は%（要素自身のサイズ比） |
| 曲線 | `ease-in-out` / `infinite` / **`alternate-reverse`** |
| ばらけ方 | duration が **1.8s / 2.0s / 2.1s / 2.2s / 2.5s / 2.8s と全部違う。delay は 0** |
| 実装 | **素のCSS keyframes だけ。**GSAPもThree.jsも無い（`lenis` はスクロールのみ） |
| alt | 全部 `alt=""` |
| keyframes名 | `floating_1`〜`floating_5`、`floating_x_1`〜`_3`、`floating_y_1`〜`_3` |

**なぜ機械っぽく揃わないのか。** `alternate-reverse` と「全部違う duration」の組み合わせで、
**delay を振らなくても位相がずれ続けて二度と揃いません。**
振幅が ±3〜5% しかないことも効いています。大きく動かすと「浮遊」ではなく「移動」になります。

### 取りこぼしていたこと

**`prefers-reduced-motion` の分岐がありません。**このLPでは足します。
リボンは装飾なので、**止めても情報は1つも減りません。**

### このLPでの意味づけ（却下済みの旧案・記録）

**リボン1本＝1組。**確定事実が「最大4〜6組のグループが**交差する**」で、
リボンは交差する物体そのものです。**本数が仕様になります。**
素材は切り抜き写真ではなく**インラインSVG** —— 画像を1枚も増やさず、色をCSS変数で差し替えられます。
**ゼブラ柄も地に敷くのをやめてリボン1本に移しました。**これで本文の下に柄が来ません。

この意味づけは2026-09-07の「リボンを採用しない」判断で終了した。
再提案を防ぐために残しており、新しいカンプへは持ち込まない。

## 2. FUTURE TRAIN —— 配色の移り変わり

`https://www.futuretrain.jp/`

依頼者の言葉: **配色の移り変わりはこのサイトを意識したい。
ネオンカラーと明るいオレンジとかをうまいこと使えたら。**

### 実装から読み取ったこと

CSS（372KB・3枚）から拾った実際の色。**宣言されているグラデーションは1本だけです。**

`linear-gradient(312deg, #2c4198 -11.85%, #c82f8b 140.46%)`

出現頻度の上位が端点 `#2b469c`（24回）と `#cf3792`（12回）で、
**残りの色が全部その補間の上に並んでいます** ——

`#21387c → #22387d → #393a86 → #523984 → #663882 → #7a3881 → #8f3880`
`→ #a3397e → #b8227c → #c82f8b → #cf3792 → #d83597 → #db4da2 → #f0549b → #ffd1ed`

**R が単調に上がって B が単調に下がるだけ。**新しい色を1つも足していません。

### ここから取った原則

**決めるのは端点だけ。セクションの色は端点の補間から取る。**
そうすると**隣のセクションと絶対にぶつかりません。**
「移り変わり」に見えるのは、色を増やしたからではなく**色を1本に絞ったから**です。

### このLPでのランプ（2端点・6ステップ）

支給バナーの色相実測（§4）と2026-09-08の比較06採用を反映し、現在は
`#24102E`（濃紫の夜）→ `#FF2D95`（ネオンピンク）の2端点に絞っている。

| | hex | 彩度×明度 | 用途 |
| --- | --- | --- | --- |
| 01 | `#24102E` | 0.118 | FV・CTAの暗い地 |
| 02 | `#5B163F` | 0.271 | 仕組みの暗い面 |
| 03 | `#8D1B58` | 0.447 | 境界の有機形 |
| 04 | `#C91F70` | 0.667 | イベント理解の広い光 |
| 05 | `#E52683` | 0.749 | ネオンの線・小面積 |
| 06 | `#FF2D95` | 0.824 | CTAだけ |

明るいオレンジ `#FF8A1F` はランプへ入れない。
支給バナーが大面積で担っているため、LP側では罫、番号、短いマークだけに使う。
マスタード `#D97706` も役目が重なるので採用しない。

**読ませる面はランプに乗せない。**淡いピンク `#F2D6DF` と白 `#FFF7FA` のカードを
ページを通して不変の可読面として使う。ランプが動かすのは色の付いた面だけ。

### 重なるカードの実装 —— 2026-09-09 に1440pxで実測

依頼者から `future-train-harness.md`（外部で作られた解析資料）を受け取ったので、
**書いてあることを実物に当てて確かめた。結論から言うと、中心の技術説明が間違っている。**

| 資料の主張 | 実測 |
| --- | --- |
| CSS Scroll Snap で吸い付く | **0件。**`scroll-snap-type` を持つ要素も `scroll-snap-align` を持つ要素も無い |
| もしくは GSAP ScrollTrigger でピン留め | **読み込まれていない。**`window.gsap` / `ScrollTrigger` / `Swiper` はいずれも undefined |
| Swiper Vertical Mousewheel | 同上。読み込まれている js は Next.js のチャンクと `three.min.js`・`splide-shader-carousel.min.js`（**別の横カルーセル用**）と計測タグだけ |
| 100vh のカード構造 | **これは合っている。**`md:h-svh` で、実測 900px = ビューポート高 |

スクロール駆動のCSS（`animation-timeline` / `scroll()` / `view()`）も **0ルール**。
**JavaScriptは一切使っていない。**

実際のDOM ——

```
section.relative.overflow-x-clip          ← overflow-x: clip
├ div      （見出しブロック / relative）
├ article  md:h-svh md:sticky md:top-0            ← 1枚目だけ貼り付く
├ article  md:h-svh mt-14 md:[clip-path:inset(0)] ← 2枚目以降が上をせり上がって覆う
├ article  （同上）
├ article  （同上）
└ article  （同上）                                ← 全5枚
```

**訂正が1つある。**このLPのハーネスには「カード間に隙間を空けない」と書いていたが、
実物には `mt-14`（56px）が入っている。実測して初めて分かった。

**この資料の扱い:** 検証済みの上記だけを採用する。GSAP・scroll-snap・Swiper は
**入れない**（このLPの「JSは使わない」という確定事項と衝突するうえ、そもそも
実物が使っていない）。資料そのものはリポジトリに置かない —— 誤った記述が
次に触る人へ再輸入されるため。

### Future Imagination Course —— イベント概要の見せ方

2026-09-08、依頼者から「Future Imagination Courseのレイアウトと、スライドしたときの流れを
イベント概要へ活かしたい」と指示があった。Visitor Guideでは、最初に楽しみ方を問い、複数の
選択肢を同じレールに並べる。選択した項目は、画像、タイトル、補足タイトル、説明、条件、導線を
持つ同じ形の詳細パネルとして表示される。Future Imagination Courseはその先頭カードで、没入体験の
説明と画像、予約導線をまとめている。公式ページの構造は、Visitor Guideの選択肢とFuture Imagination
Courseの詳細として確認できる（[FUTURE TRAIN](https://www.futuretrain.jp/ja)）。

このLPでは、固有の文章・画像・ロゴを借りず、**選択肢のレール → 同じ枠の詳細パネル → 次のカードへ
進む流れ**だけを採用する。カードは `01 WHAT IS MIX`（恋愛リアリティ体験）、`02 CHIME`
（チャイムからお題が出される）、`03 CROSS`（最大4〜6組が交差する）の3枚に翻訳する。
後で実装する際は、カード幅を基準に横へ1枚ずつ進み、画像・見出し・本文を同じ番号で同期させる。
デスクトップは矢印またはホイール、モバイルはスワイプで進め、次カードの端を少し見せる。自動再生は
せず、`prefers-reduced-motion` では横移動を止めても情報の順番と現在位置が分かるようにする。
詳細な設計値は `docs/design-docs/overview-motion-spec.md` に記録する。

## 3. SOUND TRIP —— 構成・配色・図形配置

`https://on-the-trip.com/sound-trip`

依頼者の言葉: **サイトの構成はこれをベースに進めたい。配色の使い方と図形の配置が好き。**

2026-09-07 に実ページをブラウザで開き、1280 × 720px のPC表示と、
ナビが折り畳まれる703 × 814pxのレスポンシブ表示を確認した。
DOM、算出後のCSS、読み込まれた画像とSVGを読んだ。

### 実測した構造

| 部分 | PCで確認した値・構造 | レスポンシブ表示 |
| --- | --- | --- |
| FV | 高さ972px、濃紫 `#34044A`。Aboutはy=720から始まり、**252px重なる** | 高さ814pxで、ほぼ1画面を使う |
| About | 高さ1505px。左右の装飾を別々の疑似要素へ置く | SP専用SVGへ交換し、左右の装飾が本文を避ける |
| Artist | 高さ2563px。大小2枚の流動形写真を対にして左右交互に配置 | 高さ4520pxへ伸び、1列に並ぶ |
| How To | 高さ667px。直径248pxの円形イラストを4列で反復 | 高さ1253px、2列へ折り返し、左右を上下にずらす |
| Footer | 濃紫へ戻り、中央にロゴと白いCTA | FVと同じ暗色へ戻してページを閉じる |
| 固定CTA | 画面下に高さ112pxの独立レイヤー | 本文へ重ねるが、外周と余白で別の面に見せる |

ページの地はシアン `#26C7D1`、強い暗色は濃紫 `#34044A`、
巨大な有機形は赤 `#CF264A` と明るい赤 `#E83C60`、文字と輪郭は白。
**4色を同じ面積で並べていない。**シアンを広い地として固定し、濃紫か赤の巨大な形を
1つ食い込ませ、白を文字と輪郭に使う。色数ではなく**面積差**で強弱を作っている。

### 素材とレイヤー

- FVのロゴ、見出し、スクロール記号はSVG
- Aboutは `abount_001.svg` / `abount_002.svg` を左右の疑似要素へ分離
- SPでは `abount_001_sp.svg` / `abount_002_sp.svg` に交換
- Artistの長い端装飾は `artist_001.svg`
- How Toの大きな境界形は `how_to_001.svg`
- 手順イラストは `how_to_01.png`〜`04.png`、各248 × 248px
- 写真カードは大きい画像がカード幅の約90%、小さい画像が約40%。2枚を重ねて1組にする

形をCSSの角丸だけで作っているのではなく、**各セクション専用のSVGを1枚ずつ置いている。**
同じシルエットを反復せず、地・巨大な境界形・小さな人物や記号の3段階に分けている。

### このLPへ取る構成原則

1. **FVを1画面の強い面にする。**支給キーアートを中央に置き、外周からだけ有機形を入れる。
2. **セクション境界を直線で切らない。**隣接する色面のどちらかを大きな有機形として
   10〜25%ほど次の面へ食い込ませる。
3. **中央は読ませる場所として空ける。**装飾は左右端、四隅、境界へ寄せ、本文の背面に置かない。
4. **大小を対にする。**大きな光だまりと小さな光だまり、太いゼブラ面と小さなネオン記号のように、
   1セクションの図形は「大1＋小1」を基本単位にする。
5. **同種情報は同じ輪郭で反復する。**開催情報や確定事実を並べる場合は、形を増やさず
   同じカードまたは円形フォーマットを使う。
6. **終盤でFVの暗色へ戻す。**情報面のあと濃紫へ戻し、CTAを独立した1面として見せる。
7. **固定CTAはCV確定後に採否を決める。**採用する場合は本文のカードに見せず、
   外周、余白、z-indexを持つ独立レイヤーにする。

このLPではSOUND TRIPの色をコピーしない。既存の
`#24102E → #FF2D95`ランプを地と有機形へ割り当て、`#6338D4`は交差するネオン線、
`#FF8A1F`は小さな火花・点・罫だけに残す。
ゼブラ柄は巨大な形の全面ではなく、端から入る形の一部分へクリップする。
支給キーアートの焼き込み文字がある中央には、図形も固定CTAも重ねない。

**借りるのは構成文法だけ。**ロゴ、人物イラスト、各SVGの輪郭、写真の切り抜き形、
シアンと赤の配色そのものは流用しない。

### 2026-09-08の背景再確認

背景の品質を上げるため、実ページのAbout、Artist、How Toと読み込まれたSVGを再確認した。
算出後の疑似要素では、About左の `abount_001.svg` が区間幅の約14%、右の
`abount_002.svg` が約50%、Artistの `artist_001.svg` が約11%、How Toの
`how_to_001.svg` が約70%を占めていた。Aboutの2枚は上へ約10%、How Toは上へ約30%
ずらし、境界から画面内へ食い込ませている。

`abount_002_sp.svg` は、白い波状の反復線、大きな赤と紫の色面、小さな人物・記号を
1枚の中へ持つ。ここから、背景を「大きな色面 → 中間の輪郭・パターン → 小さな記号」の
3段階で設計する原則を追加した。MIXのカンプ10では人物を写さず、ゼブラ、ネオンの輪郭線、
火花・点へ置き換えた。区間ごとに専用SVGを作り、同じ丸形の反復を避けている。

## 4. 支給バナーの色（実測・2026-09-07）

参考サイトではないが、**配色を決めるうえでこれが一番効いた。**

`img/mix-band-key.webp` を PNG に変換し、彩度 0.45 超・明度 0.5 超の画素を
15度刻みの色相で数えた（3px間隔サンプル・52250点）。

| 色相 | | 割合 |
| --- | --- | --- |
| 30〜45度 | 橙 | **30.7%** |
| 15〜30度 | 朱 | **28.7%** |
| 0〜15度 | 赤 | **19.4%** |
| 345〜360度 | 赤紫 | 7.1% |
| 210〜240度 | 青 | 6.3% |
| 315〜345度 | ピンク | **4.5%** |

**赤〜橙で 78.8%。ピンク・マゼンタは 4.5% しかない。**

### ここから出た決定

**CTAはオレンジにしてはいけない。**
ランプの終点を `#FF8A1F` にしていたカンプ03・04では、
**バナーに焼き込まれた「全員オレンジバンド」バッジと本物のCTAが、
同じオレンジのピルとして縦に並んでいた。しかも偽物のほうが上にあった。**

→ 終点を **`#FF2D95`（ネオンピンク）** に変更。
**依頼者の指定「ネオンカラーと明るいオレンジ」は、2色を別の役に割って両方使う** ——
**明るいオレンジは支給バナーが出し、ネオンピンクはLPが担ぐ。**
LP側のオレンジは**罫と番号だけ**（面には塗らない）。
配色ガイド①の「主役はマスタード」は、役目が重複するため**落とした**（要確認）。

### 保証の書き換え

以前「彩度×明度が単調に上がるからCTAが自動的に最強面になる」と書いたが、**これは誤り**だった。
**バナーのオレンジは 0.878 で、新しい終点 0.824 より上。**
**CTAが勝つ根拠は「べた塗りの面積」と「バナーが持たない色相」の2つ**で、彩度単体ではない。
