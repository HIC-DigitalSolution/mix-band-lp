# ゼブラ柄をオレンジにする（地に合わせて2種）

- **Date:** 2026-09-08
- **出どころ:** 依頼者「ゼブラ柄なんかイマイチじゃない？補色でオレンジ使ったほうが色合いいいと思うんだけど」
- **関連:** `harness/contracts/mix-lp.yaml` の `section-colors-come-from-one-ramp`

> **2026-09-09、この結論は破棄した。**依頼者の指摘 ——
> 「WHAT IS MIX右上・YOUR NIGHT右端・開催情報周辺のオレンジ反復が目立つ」。
> 縞をラズベリー `#C91F70` とベリー `#8D1B58` へ寄せ、オレンジは小さな火花・点・
> 短い罫だけに戻した。以下は「なぜオレンジに振ったか」の記録として残す。
>
> **何を間違えたか:** 1箇所で見て決めた。柄は同じ図形を何度も置くものなので、
> 1回の描画で「効いている」色は、5回置くと地の色になる。**反復するものの色は、
> 反復した状態で見て決める。**S×V が CTA より低いことは、反復の量を弁護しない。

## 「補色」という読みは、半分当たっていた

実測した色相 ——

| | 色相 | S×V |
| --- | --- | --- |
| 電気紫 `#6338D4` | 257° | 0.612 |
| ラズベリー `#C91F70` | 331° | 0.667 |
| ネオンピンク（CTA）`#FF2D95` | 330° | **0.824** |
| オレンジ `#FF8A1F` | 29° | **0.878** |

- **オレンジと電気紫は 132度差 = ほぼ補色。**紫に対しては指摘どおり。
- **オレンジとピンクは 57〜58度差 = 類似色。**ピンクの隣では補色として働かず、混ざる。

## ただし、ゼブラの問題は色ではなかった

白 `#FFF5F7`（S×V 0.039）× 黒 `#2A1030`（0.125）で、
**ページ中で一番強いコントラストを作っていた。**CTAより目を引いていたのはそれが理由。

## 4案を描いて見比べた

| | 内容 | 結果 |
| --- | --- | --- |
| A | 現行（黒×白） | ページ最大のコントラスト。**イマイチの原因** |
| B | **柄を残して、縞をオレンジ・地を濃紫に** | **採用。**柄の性格が残り、白黒の最大コントラストが消える |
| C | 柄をやめてオレンジの細線 | 傷のように見えて、柄としての性格が消える |
| D | 柄をやめてオレンジのべた面 | **セクションで一番強い面**になり、炎のような別物体として浮く（0.878 > CTA 0.824） |

**答えは「柄の色を変える」で、「柄をオレンジの面に置き換える」ではなかった。**
オレンジは縞なので実効面積が約半分で、濃紫の地に乗るぶんコントラストも落ちる。

## 地に合わせて2種持つ

**1種類では成立しなかった。**オレンジ×濃紫の縞を明るいセクション
（benefits / info、地は `#FFF7FA` と `#F2D6DF`）に置くと、
**そこがセクションで一番強い面になった**（描画して発覚）。

| pattern | 地 | 縞 | 使う場所 |
| --- | --- | --- | --- |
| `#zebra` | `#2A1030` 濃紫 | `#FF8A1F` | intro（濃い地） |
| `#zebra-light` | `#F2D6DF` 淡いピンク | `#FF8A1F` 92%・**縞を細く** | benefits / info（明るい地） |

**柄のコントラストは、乗る地に合わせる。**これが今回の決定。

## 検証していないこと

- **実機で見ていない。**確認は `tools/render.sh`（qlmanage / WebKit）で375px幅。
- **オレンジの総面積は測っていない。**「小さな火花・点・短い罫だけ」という
  もとの制約からは外れる使い方なので、増やしていくなら一度面積を測ること。

## 途中で踏んだこと

最初の比較は**CSSで `[fill="url(#zebra)"]` を上書きして4案を並べた**が、
**`<use>` の影ツリーは外側の祖先セレクタでは選択できない**ため、B・C・Dが
Aと同一に描画された。**描画して見たから気づけた** ——
見なければ「オレンジにしても変わらない」と誤って報告していた。
id を variant ごとに振り直して作り直した。
