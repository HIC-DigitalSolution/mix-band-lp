## Result

**入れた機械検査（4件）** —— `spacing-comes-from-the-scale` /
`japanese-line-breaking-stays-on` / `crops-use-explicit-coordinates` /
`no-dark-bands-at-tablet-widths`。機械検査は 24 → 28 件。

**空振りでないことを確認した。**導入した瞬間に実際に5箇所を落としており
（`margin: 0 0 18px` のように px が2番目以降にある書き方で、手作業の grep では
見つけられなかったもの）、`no-dark-bands` は `.page` の max-width をわざと戻すと
FAIL、直すと pass することを実演した。

**余白** —— `--sp-1`〜`--sp-40`（4/8/12/16/20/24/32/40/48/56/64/80/96/120/160px）。
それまで実際の padding が28種類ばらついていた。節の縦リズムは SP 80/80、PC 160/160。

**中間幅** —— `.page` の上限を外し、`--sp-edge`（900px未満）と `--pc-edge`（以上）で
中身の列だけ留める。768pxで169px、899pxで234px出ていた濃紫の帯が 0px になった。

**追従CTA** —— PCは右下の小型ピル（200x71px）。1440で画面内の本文8件と重なり0件。
SPは全幅の帯のまま（画面下部は構造上どうしても覆う）。

**HTML** —— benefits の末尾に `</div>` が1つ余分だった。削除してタグ不整合0件。

**FV** —— 支給バナーは人物もタイトルも焼き込まれた1枚の平画像で、人物だけを
動かすことはできない。写真は静止のまま、手前に12個の火花を重ねた。
焼き込みタイトルには重ねず、duration は全部別値。

**残っているもの**

- 背景SVGの歪み（A/B/C の判断待ち）
- 「いつもと違う夜に物語を」の短縮方針（画面高をやめるか、3枚を2枚にするか）
- アートディレクションの不一致（FVは支給のAI広告ビジュアル、本文は実写1枚の切り出し
  ＋支給ベクター。**素材が揃わないとCSSでは揃えられない**）
- 店舗名・公式LINE URL（最後の工程）
- og:image / og:url / noindex 解除（公開先確定後）
