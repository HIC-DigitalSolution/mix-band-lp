# 導入セクションを全面写真のパネルにし、YOUR NIGHT の写真を差し替える

- **Started:** 2026-09-09
- **Rule:** `harness/contracts/mix-lp.yaml` の `mememe-full-bleed-panel-grammar`
- **Completed path:** `docs/exec-plans/completed/intro-full-bleed-panel.md`

## Goal

レビューで最大の問題とされた「FVと本文が別のデザインに見える」を、素材を揃えることで縮める。

## Constraints

- index.html は手書き、CSS は Sass からのコンパイル物のみ
- **GSAPを入れない**（JS無しで何が壊れるか言えないものは足さない）
- 白文字の可読性は目視で決めず、画素から計算する
- **push / デプロイは依頼者の指示があるときだけ**

## Scope

- [x] 導入を全面写真＋被せ＋白文字のパネルにする
- [x] タイトルを支給ロゴ（FVと同じ字形）に差し替える
- [x] 1行ずつ遅らせて出す動きを入れる
- [x] YOUR NIGHT の3枚を別々の場面の写真に差し替える
- [x] FVを新しい支給素材に差し替える

## Non-scope

- FVバナーの「1日限り」（画像に焼き込まれており、コードでは直せない）
- 背景SVGの歪み（別件）

## Acceptance

- [x] 白文字のコントラストが AA 本文基準 4.5 以上
- [x] JSが動かない環境でも本文が見える
- [x] 3枚のカードが別々の場面・別々の人数・別々の距離
- [x] 全幅で横スクロールなし、画像の欠けなし

## Verification

- [x] `node scripts/harness/harness-check.mjs`
- [x] `node scripts/build.mjs`
- [x] 実画面計測（390 / 1100 / 1440）
- [x] コントラストを画素から計算
- [x] `is-armed` を外してJS無しの状態を再現

## Result

**導入セクション** —— `img/intro-scene.webp`（引きの店内・乾杯・ビアポン・ビリヤード）を
全面に敷き、濃紫 `#24102E` の縦グラデーション（.58 → .88）を被せた。
**黒の乗算にしていない** —— mememe の実物はブランド色を30%かぶせており、黒だと写真が
灰色に寄ってネオンが死ぬ。白文字の最悪コントラストは **6.77:1**（写真の最も明るい画素で計算）。

タイトルは支給ロゴ `img/mix-logo.webp`（853x216・FVと同じ字形）。文字情報は alt が持つ。
本文は1行1要素・中央揃え・行間2.0・字間0.08em（mememe の実測値）。

**出現アニメーション** —— `js/reveal.js`。`[data-reveal]` の子を 0.09s ずつ遅らせる。
opacity と translateY だけを動かし、レイアウトは動かさない。
**既定は「見える」**で、隠すのはJSが `is-armed` を付けたときだけ。JS無しの状態を
再現して全要素が見えることを確認した。`prefers-reduced-motion` の保険も別途置いた。

**YOUR NIGHT** —— 支給された3枚に差し替え。01 ビアポン（球が空中・4人）／
02 カウンターの2人（男性が笑う女性の横顔を見ている）／03 ビリヤードの6人（引き）。
**人数と距離が3枚とも違う**ので、スクロールで場面が進む。以前は集合写真1枚の切り出しだった。
02 は最初に寄せすぎて女性の顔が切れたため、両方の顔位置を基準に切り直した。

**FV** —— 新しい支給素材（1672x941）。PCとSPを**同じ原本から**切り出しており、
幅を変えても出演者が入れ替わらない。

**残っているもの**

- FVバナー上部の「1日限りの恋愛リアリティ体験」（焼き込み。素材の作り直しが必要）
- 背景SVGの歪み（節ごと 0.56〜2.45）
- 店舗名・公式LINE URL（依頼者の指示で最後の工程）
