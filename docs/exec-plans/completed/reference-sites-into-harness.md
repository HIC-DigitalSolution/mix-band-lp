### カンプ02/03が「ぐみみたい」で差し戻された（同日・追記）

**CSSは正確に読んだのに、素材画像を1枚も開いていなかった。**
`assets/line/hero01.webp` を `curl` して見たら、太さ一定の管とは完全な別物だった ——
**ポスターカラーのべた塗り／幅が大きく変わる／縁は手切り／ねじれが硬い折り目で裏面が別色／
画面外に切れていく巨大な断片。**「布」ではなく「棒」を描いていた。

直し方: 背骨（cubic）と**幅の関数**からSVGパスを生成する方式に変更。
ねじれ位置で幅をくびらせ、そこから裏面色に切り替えて折り目にする。
縁のジッターは ±0.7 に抑え、**数箇所だけ**大きく欠かせる。
絵の具のざらつきは `feTurbulence` を `feComposite operator="in"` で形の内側に閉じ込める。

| 描き直し | 実際に見た結果 |
| --- | --- |
| 1回目（stroke一定・グラデ） | **グミ。**差し戻し |
| 2回目（ジッター強・全体） | **破った紙。**布に見えない |
| 3回目（ジッター弱・局所欠け＋幅可変＋折り目） | **布。**採用 |

**FVの構成も直した。**リボンを置いてから描画して見たら、
**バナーが375幅をほぼ埋めてリボンの居場所が無く**、端に切れ端が覗くだけだった。
さらに `z-index:5` の2本が**バナーの上に乗って焼き込み文字に重なっていた**（自分のルール違反）。
→ バナーを 295px に縮めて内側に寄せ、**FVのリボンを全部背面（z-index:1）に落とした。**
**`ASOBIBAR` の文字段も削除** —— ロゴはバナーに焼き込まれているので二重だった。

### CTAの色が間違っていた（同日・追記。カンプ05で修正）

依頼者から「**描画して見るように今後徹底してください**」と指示され、描画の経路を作った
（`tools/render.sh`）。**その1枚目で、自分のカンプの致命的な欠陥が出た。**

**支給バナーの「全員オレンジバンド」バッジと、私のCTAが、同じオレンジのピルとして
縦に40px間隔で並んでいた。しかも偽物のほうが上にあった。**

バナーの色を実測した（彩度0.45超・明度0.5超の画素を15度刻み・52250点サンプル）——
**赤〜橙で 78.8%（橙30.7／朱28.7／赤19.4）、ピンク・マゼンタは 4.5%。**

→ ランプの終点を `#FF8A1F` から **`#FF2D95`（ネオンピンク）** に変更。
**「ネオンカラーと明るいオレンジ」は2色を別の役に割って両方使う** ——
オレンジは支給バナー、ネオンピンクはLP。LP側のオレンジは罫と番号だけ。

**前に書いた保証は誤りだったので取り消した。**
「彩度×明度が単調に上がるからCTAが自動的に最強面になる」は成り立たない ——
**バナーのオレンジ 0.878 は新しい終点 0.824 より上。**
CTAが勝つ根拠は**「べた塗りの面積」と「バナーが持たない色相」**の2つ。

**恒久化したもの:** `mix-lp.yaml` に `output-is-rendered-and-seen`（manual・21行目）、
`design-comp.yaml` に3ステップ（参照はCSSと素材の両方を見る／支給素材の色相を実測する／
描画して見て古い記述が残っていないか確かめる）、`AGENTS.md` の作法に3項目、`tools/render.sh`。

### ヘッドレスChromeが使えなかった

`--headless=new` は `--virtual-time-budget` を付けても**45秒で返ってこない。**
`feTurbulence` が原因という仮説を立てたが、**フィルタの無いカンプ03も同じくタイムアウトした**ので
外れ。**原因は未特定。**`qlmanage -t`（QuickLook / WebKit）を本線にした。
`.dc.html` は doctype も charset も持たないので、**包まずに描画すると UTF-8 が化けて
「見たつもりで何も読めない」**（1回目でこれを踏んだ）。`render.sh` が包む。

### 途中で見つけて直したこと

- **カンプ01は「イマイチ」で差し戻された。**原因は平らな面を積んだだけで、
  **MIXが画に一度も出ていなかった**こと。依頼者の指摘が正しい。
  → リボンが交差する「交わる面」（ramp-03）を意味の中心に置いた。
- **`required-content` は「対象になった各ファイルが全パターンを持つ」判定**だった。
  `^css/.+\.css$` に広く当てるとCSSを2枚に割った瞬間に両方へ同じ要求が出る。
  **これは承知で採用した** —— このLPはCSS1枚と決めているので、2枚目が現れたら気づける。
- ブラウザペインが隠れていると**スクリーンショットが白く写る**（自分で
  `.claude/skills/design-comp/SKILL.md` に書いた注意そのもの）。
  → 画で見るのをやめ、DOMとCSSを読む方に切り替えた。**結果的にそちらが正確だった。**
