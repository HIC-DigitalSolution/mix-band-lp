# 人物のポーズを読みやすくするカンプ13

- **Started:** 2026-09-08
- **Rule:** `harness/scenarios/design-comp.yaml`, `harness/contracts/mix-lp.yaml`
- **Completed path:** `docs/exec-plans/completed/refine-human-motif-comp-13.md`

## Goal

カンプ12の人物表現を見直し、幾何学図形ではなく、頭の向き・髪・肩・腕・手が読める男女のポーズへ
作り直す。参考サイトのように人物を独立レイヤーとして扱い、中央でグラスが交わるカンプ13を作る。
その後、依頼者からSOUND TRIPの人物スケールを参照するよう再指定があったため、カンプ13は比較用に残し、
小さな人物・記号へ戻したカンプ14へ置き換える。

## Scope

- [x] カンプ12を複製し、カンプ13として編集する
- [x] 頭・髪・肩・腕・手の輪郭を持つ男女のポーズをインラインSVGで追加する
- [x] 中央のグラスと火花、写真とのレイヤー順、静止の扱いをA3決定ボードへ記録する
- [x] 人物表現の見直しを設計文書へ記録する

## Non-scope

- 本番の `src/index.html`、`src/sections/`、Sass、JSへの実装
- 支給バナーの人物、ロゴ、焼き込みタイトルやコピーの編集
- 新しい写真素材やAI生成素材の追加
- 人物を実在キャラクター風に描き込むこと、音、イントロ画面の追加

## Constraints

- 比較06の濃紫・電気的な紫・ラズベリーピンクを主軸にし、オレンジはグラスと火花だけにする
- シルエットは写真と別レイヤーに置き、中央のタイトル・日付・CTAを覆わない
- 顔は視線と鼻先の短い線だけにし、衣装やキャラクター性を描き込まない
- 既存の `prefers-reduced-motion` 方針を維持し、シルエット自体は静止させる

## Acceptance

- [ ] 375pxのHTTPブラウザ表示で、タイトル・日付・CTAへの干渉と横スクロールがない
