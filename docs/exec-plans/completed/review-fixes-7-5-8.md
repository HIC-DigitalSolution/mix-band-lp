## Result

**#7** —— 円は写真の 左7% / 上14% から36%幅で、上半分の顔に乗っていた。
下半分（卓とグラスの帯）へ移動。実測 上46% 〜 下85%、はみ出し0。
位置は px ではなく % で持たせた（写真の大きさが幅で変わるため）。

**#5** —— 巨大英字を4つ（AFTER DARK / CHIME / OCT 2026 / STEP IN）とCSS13箇所を削除。
どれも隣の日本語と内容が重複していた。**1つも残していない** ——
1つだけ残すと置き場所が恣意的に見えるため。アクセントとして戻すなら CTA が置き場。

**#8** —— CTAに店内写真を opacity .34 で敷いて余韻を戻した。濃紫を強くかぶせて、
ネオンピンクのCTAが最強面である関係は崩していない。
ダイアログは 左に店舗名とエリア、右に「公式LINE」のピル。行79px、ダイアログ540px（画面844）。

**踏んだ罠** —— 旧 `.store span` の `color` と `::after { content: " →" }` が
新構造の両方の span に当たり、**ピルの文字がピンク地にピンク文字で消え、矢印が余分に出た。**
`dialog-rows-are-choices-not-links` に「要素セレクタを書かない」として記録した。

**#4** —— 見出しを役割で分けた。体験価値 24/38（オレンジの短い罫）／仕組み 24/42（詰める＋
薄いグロー）／事務情報 20/26（一番静か・字間広め）／締め 28/48（一番大きい・強いグロー）。
**足したのは字間・大きさ・グロー・短い罫の4つだけ** —— 書体を増やしたり縁取りをしたりすると
FVの立体ロゴと競合して安っぽくなる。

**記録済みの上限を1つ書き直した** —— 「SP見出しは24px上限」の本体は数字ではなく
「意図しない折り返しを出さないこと」。締めの「今夜の舞台へ」は6文字なので28pxでも
375pxで1行に収まる（幅343px、`<br>` 数と行数が一致）ことを実測して例外にした。
**長い見出しは24pxのまま。**

**店舗リンク** —— 依頼者から出どころ（asobibar.net/shops/）を指定され、10店舗を入れた。
**ダミーリンクは0件になった。**エリア区分も公式の「東京エリア」等をそのまま使い、
推測で書いた項目は無い。`lin.ee/fpDqfH8` が4店舗で重複しているが、**公式サイト側が
そうなっている**（DOMを2通りの方法で照合して確認）。誤りなら依頼者が直す。
ダイアログは806px（画面844）でスクロール可、行79px。

**店舗は「全店」ではない** —— 2026-09-09、依頼者の指示で梅田茶屋町店を外した
（この施策は実施しない）。**店舗一覧を機械的に写さないこと。**載せるのは実施する店だけで、
どの店が対象かは依頼者にしか分からない。ハーネスの「全店開催」という記述も直した。

**OG** —— `img/ogp.jpg`（1200x630・206KB）を支給バナーから作った。
**上端の「1日限りの恋愛リアリティ体験」が半分切れるので、その行を外す位置で切っている。**
og:url と og:image は絶対URLで入れたが、**値は GitHub Pages の暫定URL**。
**noindex はまだ外していない** —— 本番ドメインが決まってから3つ同時に直す。

**CTAの色** —— 依頼者の指示でロゴと同じオレンジ系にした。**記録済みの「CTAはオレンジにしない」を
意図的に覆している。**単色は避け、ロゴと同じ 明るいオレンジ→濃い赤のグラデーション＋濃い赤の縁に
して、支給バナーの「全員オレンジバンド」ピルと見分けが付くようにした。文字は白では読めないので
濃色 #2A0F06（コントラスト 明るい端10.82 / 暗い端4.71 を実測）。

**重なるカード** —— 1枚目しか sticky にしておらず、3枚目が2枚目の上へせり上がっていなかった。
**全部を同じ top で sticky に**し、`margin-top: -22vh` で重なり始めを早めた。
実測で2枚目323px・3枚目700pxのスクロールで貼り付く（以前は1枚ぶん約580pxずつ）。

**フッター** —— ロゴを公式HPへのリンクにした。当たり判定44px。

**重なりの詰めは即日戻した** —— 依頼者「SPで見たら文字なんも見えないんだけど」。
負の上マージンで重なり始めを早めたら、**止まっている状態で前のカードの本文が
次のカードの下に隠れた**（1枚目253px・2枚目184px）。本文はカードの下端まで使うので、
負の値はそのまま文字を消す。`margin-top: 0` に戻した。全部 sticky にした変更は残す。
**速さを上げたいときは重なりではなくカードの高さで調整する。**
