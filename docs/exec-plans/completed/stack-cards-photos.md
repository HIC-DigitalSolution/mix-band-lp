- **Started:** 2026-09-08
- **Completed:** 2026-09-09
- **Rule:** 2026-09-08 の依頼者の判断（カードの白が余るので中身を足す＝写真）

## Goal

「いつもの夜を予定外に」の3枚に写真が入り、白が余らない。
**3枚が別々の人・別々の表情**で、使い回しに見えない。

## Scope

- [x] 手持ちの実写を数える
- [x] 原本から人物ごとに切り出す
- [x] 切ったものを**先に並べて見る**
- [x] カードに写真の枠を作る
- [x] ハーネスの記述を実装に合わせる

## Non-scope

- 新しい写真の支給依頼。**手持ちで足りた。**
- カードの枚数・順番の変更。

## Constraints

- `image-budget` は1枚400KBまで。
- 3枚とも別の人にする（同じ人が2枚に写ると使い回しに見える）。
- sticky を壊さない。

- [x] 主役の人物が重なっていない
- [x] sticky が親の範囲で正しく効く

### 切り直しを1回している

最初の切り位置（x=480）だと、**1枚目に2枚目の主役（口を覆う女性）が写り込んでいた。**
並べて見て気づいたので x=340 へずらし、1枚目を「カードを見せる男性＋笑う男性」の2人にした。
**同じ場面から切るときは、主役が重ならないかを並べて確認する。**

### なぜ同じ場面から3枚切ってよかったか

**カードは重なって1枚ずつ見える構造**なので、2枚が同時に画面に並ぶことがほとんどない。
横に並ぶギャラリーだったら、同じ場面の切り分けは使い回しに見えたはず。

### 検証していないこと、残っているリスク

- **実機で見ていない。**確認はブラウザの375pxエミュレーションと qlmanage。
- **写真は全部同じ夜・同じ4人。**イベントの実写としては自然だが、
  **別の日・別の参加者の写真が来たら差し替える価値がある。**
- 3枚とも `chime01` 由来なので、**`chime02`（チャイム節）と人物が重複している。**
