# CSSは読んだのに、絵を見ていなかった

- **Date:** 2026-09-07
- **どこで:** MIX交流上等バンドLP のカンプ（`design/mix-lp-comp-02/03`）
- **関連:** `harness/contracts/mix-lp.yaml` の `reference-seen-before-genre`
  と `floating-objects-follow-one-physics`、`docs/design-docs/reference-sites.md`

## 何が起きたか

依頼者から「所々オブジェクトが浮いている」と参考サイト（`kbc.co.jp/70th/`）を渡された。
**DOMとCSSを読んで、技法を正確に取った** —— 3層構造、振幅±3〜5%、
duration が全部違って delay 0、`alternate-reverse`、素のCSS keyframes。
数値はすべて実装から拾った本物で、1つも推測していない。

**そのうえで、リボンを太さ一定の丸い棒として描いた。**

依頼者の反応は「**このぐみみたいなの浮いてるけど何これ。参考サイトと全然違くない？**」だった。

## 原因

**`assets/line/hero01.webp` を一度も開いていなかった。**
CSSに書いてあるのは「どう動くか」だけで、「**何が**動くか」はCSSに書いていない。
画像を1枚 `curl` して見たら、まったく別物だった。

| 実物 | 私が描いたもの |
| --- | --- |
| ポスターカラーの**べた塗り**。わずかにざらつく絵の具の質感 | ツヤのあるグラデ入りの管 |
| 幅が**大きく変わる**。片端が尖って中央が広い | **太さが一定** |
| 縁が**手切り**。基本は滑らかで数箇所だけ欠ける | 完全に滑らかなベジェ |
| ねじれが**硬い折り目**で、**裏面が別色** | ハイライトの線1本 |
| 巨大で**画面外に切れていく断片** | 全体が収まった1本 |

**「布」ではなく「棒」を描いていた。**技法が正しくても、形が違えば別のデザインになる。

## 教訓

**参考サイトでは、CSSと素材の両方を見る。**
CSSは振る舞いしか語らない。**形・塗り・質感・スケールは素材画像にしか無い。**
`curl` で1枚落として `sips -s format png` で変換すれば見られる。8KBだった。

**そして、自分の出力も見る。**
2回とも、描画を一度も確認せずに publish して差し戻されている。
`qlmanage -t -s 1220 -o . x.svg` でSVGはラスタライズできる。
**HTMLで直接見られないなら、等価なSVGに起こして見る。**
ブラウザペインは隠れていると**白く写るので使えない**
（`nfd-path-breaks-string-compare.md` とは別件だが、同じ「確認したつもり」の類）。

## やったこと

背骨（cubic ベジェ）と**幅の関数**からSVGパスを生成する方式に変えた。
幅を `t` の関数にできるので、尖った端・ねじれのくびれ・広い腹が作れる。
ねじれ位置で幅をくびらせ、そこから**裏面色に切り替える**と折り目に見える。
縁の手切りは決定論的なノイズを小さく（±0.7）入れ、
**数箇所だけ**大きく欠かせる（全体に強くかけると「破った紙」になる。これも一度失敗した）。
絵の具のざらつきは `feTurbulence` を `feComposite operator="in"` で形の内側に閉じ込める。

**そのうえで、コンタクトシートに起こして3回描き直した。**
1回目=グミ、2回目=破った紙、3回目=布。
